## Contribution workflow

1. Fork this repository to the GitHub account used by your team.
2. Clone your fork and create a feature branch for your work.
3. Commit changes from your team members to that fork.
4. Open a pull request from your fork back to this repository's `main` branch.
5. Add a clear summary, setup steps, and screenshots or demo links to the pull request.

Keep this public starter repository as the upstream project. Do not push directly to it.
